프로젝트 개요

문제와 기회단순한 이미지 감상을 넘어 손짓으로 좋아하는 캐릭터를 직접 소환하는 참여형 팬 경험을 만들고자 했습니다.
핵심 인터랙션손 랜드마크 → 규칙 기반 손모양 판정 → 캐릭터 이미지 픽셀 샘플링 → 색상 파티클의 이동·변형.
AI / Computer Visionml5.js Handpose 모델을 이용한 손 관절 랜드마크 추정. 원본 코드에서 별도 일반 객체 탐지 모델은 확인되지 않았습니다.
제작 방식p5.js 시각화와 JavaScript 인터랙션. 바이브코딩 활용은 제작자 설명에 따르며, AI 기여 범위는 추가 기록이 필요합니다.

구현 과정

  1. 브라우저에서 웹캠 스트림 획득 (p5.js createCapture)
  2. ml5.handpose로 손 랜드마크 추정
  3. 손가락 끝과 중간 관절의 Y좌표 관계로 손모양 분류
  4. 선택된 캐릭터 이미지의 유효 픽셀을 샘플링해 파티클 목표점 생성
  5. 매 프레임 좌표·RGB·투명도를 보간해 파티클 모핑 표현
  6. 모바일/데스크톱별 최대 파티클 수·크기 조정

기술 및 검증 수준

JavaScript, HTML/CSS, p5.js, ml5.js Handpose, 브라우저 웹캠 API, 이미지 기반 파티클 렌더링, 정적 웹 배포 대응. 본 프로젝트는 손 관절 기반 제스처 분류이며 별도 학습시킨 사용자 정의 객체 인식기·전신 자세 추정기는 현재 소스에서 확인되지 않습니다. 웹 배포 환경에서 카메라 권한·성능·모바일 인식 정확도는 별도 실기기 검증이 필요합니다.

권리 및 사용 범위

비공식 치이카와 팬 프로젝트이며 공식 제작사·권리자와 무관합니다. 사용된 캐릭터 리소스의 권리는 원 권리자에게 있습니다. 공개 GitHub 저장소/Pages 배포 시 이미지 사용 허가 또는 대체 리소스를 검토해야 합니다.
