# Dreamy — 치이카와 손동작 인터랙션 ✨

> **비공식 팬메이드 프로젝트** · 치이카와 원작 및 공식 권리자와 관계없습니다. 캐릭터 이미지 저작권은 각 권리자에게 있습니다. 공개 배포 전 리소스 사용 권한을 검토하세요.

웹캠 속 손동작을 추정해 치이카와 세계의 캐릭터들을 **파티클 애니메이션**으로 소환하는 인터랙티브 웹아트 프로젝트입니다. 취향 기반 팬 경험과 AI 비전 인터랙션을 결합했습니다.

- **체험 페이지:** GitHub Pages 배포 후 주소 추가 예정
- **포트폴리오:** `portfolio.html` — 같은 GitHub Pages에서 확인 가능
- **인스타그램 시연 영상:** 추후 추가 예정

## 직접 체험하는 방법

1. Chrome/Edge 등의 브라우저에서 HTTPS 배포 주소를 엽니다.
2. 카메라 사용을 허용합니다.
3. 카메라 앞에 손 하나를 보여주고 동작을 바꿉니다.

| 손동작 | 실제 구현된 효과 |
|---|---|
| ✊ 주먹 | 치이카와 파티클 등장 (3개 이미지 중 랜덤) |
| ✌️ V, 검지·중지 펼침 | 우사기 파티클 등장 (3개 이미지 중 랜덤) |
| 🤘 검지·새끼 펼침 | 하치와레 파티클 등장 (3개 이미지 중 랜덤) |
| ✋ 네 손가락 펼침 | 파자마파티즈 이미지 파티클 등장 |
| 👋 손을 카메라 밖으로 | 파티클 흩어짐/페이드아웃 |
| **R 키 / 초기화 버튼** | 모든 파티클 즉시 제거. 손을 잠시 뺐다가 다시 보여주면 재시작 |

> V 판정은 검지·중지가 펴지고 나머지 손가락 중 적어도 하나가 접혀 있으면 성립합니다. 엄지 판정은 사용하지 않습니다. `🤘`는 검지·새끼를 펴는 손모양입니다.

## 구현 아키텍처

```text
Browser Camera → ml5.js Handpose (손 관절 랜드마크 추정)
  → Y좌표 기반 규칙 제스처 분류
  → 대상 이미지 픽셀 샘플링
  → 파티클 목표 좌표·색상 매핑
  → p5.js 보간·이동·모핑 렌더링
```

- **AI/비전:** ml5.js Handpose 손 랜드마크 추정 (핸드 포즈 추정).
- **객체 인식 표현의 범위:** 현재 코드에는 별도의 일반 객체 검출 모델은 없습니다. 포트폴리오에는 *손 검출 및 손 랜드마크 기반 제스처 인식*으로 기술하는 것이 정확합니다.
- **시각화:** p5.js, per-particle 좌표·색상·투명도 보간, 이미지의 RGBA 샘플링, 랜덤 이미지 선택.
- **최적화 시도:** 화면 폭에 따라 최대 파티클 수/입자 크기 조절. 성능의 정량 벤치마크는 없습니다.
- **바이브코딩:** 제작자 설명에 따라 AI 보조 코딩을 사용했습니다. 정확한 도구·프롬프트·수정 범위는 추후 확인 및 보강 대상입니다.

## 파일 구성

- `index.html` — 인터랙션과 체험 가이드
- `sketch.js` — Handpose, 제스처, 파티클 애니메이션, R 초기화
- `style.css` — 반응형 레이아웃
- `portfolio.html` — 채용/포트폴리오용 기술 설명 페이지
- `p5.js`, `ml5.min.js` — 원본 제공 라이브러리(출처·버전 확인 권장)
- `*.png` — 제공된 캐릭터 이미지(권리 확인 필요)

## GitHub Pages로 배포

1. GitHub에서 새 저장소(예: `dreamy-chiikawa-hand-interaction`)를 만듭니다. 권리 상태를 검토하기 전까지 Private으로 시작하는 것을 권장합니다.
2. 이 패키지의 **내부 파일들을 저장소 루트**에 올리고 `main`에 커밋합니다. 압축 ZIP 파일만 올려서는 페이지가 실행되지 않습니다.
3. `Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save`로 설정합니다.
4. Pages가 완료되면 제공된 HTTPS 주소에서 웹캠 접근을 허용합니다. 일부 계정/저장소 플랜에서는 Pages 공개 범위 제한이 있을 수 있습니다.
5. `https://<계정>.github.io/<저장소>/portfolio.html`에서 포트폴리오 페이지로 접근합니다.

## 개발 환경에서 실행

파일을 더블클릭하는 대신 프로젝트 디렉터리에서 로컬 서버를 엽니다.

```bash
python -m http.server 8000
```

`http://localhost:8000`에서 카메라 권한을 허용합니다. 웹캠은 HTTPS 또는 localhost 등 보안 컨텍스트가 필요합니다.

## 한계 및 검증 현황

- 소스 정적 분석으로 기능을 확인했으며, 실제 사용자 카메라·모바일 기기에서 최종 동작 테스트를 완료했다고 주장하지 않습니다.
- 최초 로드 시 로컬 `ml5.min.js`/`p5.js`와 Handpose 모델이 정상 로드되어야 합니다. 모델 로딩에는 네트워크가 필요할 수 있습니다.
- 현재 제스처 분류는 엄지를 제외한 각 손가락 관절의 세로 위치만 비교하므로 회전된 손/가려진 손/일부 손모양을 잘못 판정할 수 있습니다.
- 캐릭터 IP와 사용된 이미지 라이선스는 별도 검토가 필요합니다.
